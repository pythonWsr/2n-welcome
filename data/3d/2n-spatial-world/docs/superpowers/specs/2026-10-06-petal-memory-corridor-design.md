# 花瓣记忆廊设计规格
日期：2026-10-06（北京时间）
状态：用户已在 2026-10-06 回复“继续”批准本规格；实施计划待审核。取代上一版历史章节的原位换字方案。

## 目标与范围
故事章节离开五境地图，成为独立、连续的 3D 花瓣记忆廊。三幕即使隐藏文字，也应从构图与动作上区分相遇、延续、繁盛。
保留前面五境、人物、v45 世界长链、高清资产与首页动画；只重做故事。保留花瓣长链、黑暗中的尘埃和光束。不导入或复刻首页金属 2n 的造型、轮廓、入场、打光顺序或汇聚圆环。收尾继续暂停。

## 内容
content/history.json 的三段已批准文案、日期、顺序全部保留。人物继续使用 content/people.json。
第三幕不把任意花瓣标成首个 Unique；具体种类未确认。以花瓣群落表达繁盛，以文字说明 Unique 里程碑。
血祭动作仅是象征演绎；不新增 MOB、战斗结果或获得方式。

## 时间与镜头
总长 36 秒，手动距离 6.4 单位。旧章节绝对进度坐标不变。
0–4 秒：从最终人物姿态接续，长链弯向远处形成通道；人物文字退场，地图通过距离与章节退场淡化离开画面。镜头进入独立空间，禁止瞬移。
4–12 秒：相遇。多束长链从不同方向相接，形成开放、非圆环的花瓣拱。镜头侧前方穿入；正文区域在中部，上下主体不形成旧人物固定两排。5–11 秒完整阅读。
12–15 秒：拱形延伸成起伏长链，镜头沿链移动；两段正文不同时出现。
15–24 秒：血祭。暗红光只覆盖主体。一条花瓣长链向下弯、再上扬，花瓣依次沉下、翻转、升起；镜头从侧面下降再抬升。16–23 秒完整阅读。
24–27 秒：上扬长链向远处分枝，不闪现另一套花瓣。
27–36 秒：繁盛。长链展开成不对称、非闭合环的立体花冠。镜头从近景拉开，逐层揭示已有花瓣和花朵。28–36 秒完整阅读，末端保留场景和重播入口。
位置、朝向、花瓣状态、透明度全部按统一进度连续采样；反向滑动还原，快速跨章节也正确，无强制吸附/翻页。

## 空间与视觉
独立深蓝灰空间，远处有限的体积层次；不使用五境地表，也不能把所有背景变成无层次的纯黑。
三幕局部光分别暖白、暗红、淡金；少量宽而柔和的光束斜穿空间，尘埃仅在受光区域较明显。光束不指向金属 logo，不复刻首页揭幕。
长链具有连续方向、近中远景深、适中花瓣尺寸、可见间隙和微浮动。每片采用现有高清模型；位置间隔依包围球与呼吸幅度决定，禁止互穿。花瓣正面优先朝镜头，保留少量自然倾角。
不增加高成本全屏 bloom、多层实时体积光或移动端新增动态阴影。光束使用低复杂度透明体，尘埃使用点实例。
暖白文字无黑色描边，正文手机目标 18–20 CSS px；标题 28–34 px，日期 14–16 px。正文完整保留，实测字形换行。文字中部阅读区域无近景花瓣穿过；柔和暗部提供对比。字体局部失败仍可重试，不拖住首屏。

## 资源与生命周期
复用已加载高清花瓣/花朵的几何与纹理，不复制纹理下载、不降低质量。场景布局在前半程空闲帧准备，不加入首页加载门槛。
旧地图、旧人物链和独立故事链的显示权按章节交接，不同时留下重复两排。故事共享模型资源不由自身 dispose 销毁。
主体实例总预算手机不超过 96、桌面不超过 144；优先保证长链连续与近景品质。尘埃预算手机不超过 240 点、桌面 480 点；与首页原尘埃不叠加渲染。预算是新增章节运行期上限，不改变前面的密度。
退出章节时还原环境/雾/灯光；反向进入人物不影响原五区背景。

1. 三幕静态构图/关键镜头先完成，提供原 Sites 可查看版本；隐藏文字也能辨识三幕。此阶段明确为构图预览，不宣称完整动画。
2. 构图方向确认后接连续形态、镜头、尘埃光束与可逆滑动。
3. 接文字、自动播放、局部重试；完成一次相关检查和必要构建，部署原 Sites。
每个阶段保存 GitHub checkpoint、状态和下一步。GitHub main/Pages 与旧 Llhleo/2n 本轮不改。
重点检查：人物接缝/倒滑恢复、跳段无残影、移动端文字可读、无花瓣互穿、资源失败后可重试。手机真实视觉另由实机验收，不以数学检查代替。
