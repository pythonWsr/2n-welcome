# 加载可靠性与人物展示修复

基线：线上 Sites v45，源码 `ab21017a14ed7267120a260394c75841dba200aa`。从线上实际源码恢复，未重做已完成资源。开发分支 `experiment/lookback-v2`。

## 本轮修改

- 加载：可选 Cache API 读取限制为 800ms，缓存写入退出关键路径；缓存保存无损压缩字节，原模型仍执行尺寸、GLB 魔数、SHA-256 校验。21 个高清模型原始共 44.21MB，已有无损传输共 32.20MB；未降低网格、贴图或字体质量。
- 高清资源下载与解析持有同一个有界任务槽，最多两份高清任务在途，避免大量已下载 GLB 堆积等待图片解码。失败批次取消尚未开始的任务，成功资源保留；高清传输已有原文件回退，不再重复整套自动下载尝试。区域网络并行维持原设置；慢设备解码允许最多 90 秒，而非 30 秒误判失败。
- GPU 预热保留所有模型上传，每四个模型让出一次帧；动画帧有 40ms 定时回退，编译有 30 秒超时。地面异步准备捕获错误并允许重试。
- 重试：所有准备分支结算后才启用按钮，避免上一批任务未完成就重复准备。按钮显示“准备中…”与错误原因，触控面积至少 44px；有效重试保留成功资源，不刷新页面。
- 人物字体加入单次 SDF 渲染的深色细描边，维持原白色字体和高清 SDF，不增加第二个文字绘制材质。
- 旧花瓣环原地缩退，不再展开为两列。第一位管理层阅读前明确隐藏；反向滑动仍恢复原旅程和地面实例。
- 花瓣环境去重相近镜头生成的重复簇，降低过密链条尺寸；按真实定向模型包围盒与完整浮动包络联合检查间距，连续缩放避让，不引入新的身份切换。保留真实世界位置、高清几何和五区域。
- 手动滑动：花瓣候选按模型预分组，复用打分对象；缓存静态人物位置；每帧可见度仅投影文字总包围盒，准确字形测量仍用于真实排版。阅读预算、自动播放时长和原镜头动画不改。
