二、调用接口（官方公开）
1. 花瓣图片
https://florr.io/petals/{id}.svg                  # Common / 基础版
https://florr.io/petals/{id}_{rarity}.svg         # 带稀有度（1~9）
示例：
	•	Basic 普通：https://florr.io/petals/1.svg
	•	Light 史诗：https://florr.io/petals/2_3.svg
	•	Rose 超级：https://florr.io/petals/5_7.svg
2. 怪物图片
https://florr.io/mobs/{id}.svg
（怪物图片通常不按稀有度拆分 SVG，稀有度由游戏内渲染）
3. 文本 / 数据文件
https://florr.io/static/i18n/en_US/petals.txt
https://florr.io/static/i18n/en_US/mobs.txt
https://florr.io/static/i18n/en_US/rarities.txt
https://florr.io/static/i18n/zh_CN/petals.txt     # 中文
https://florr.io/static/i18n/zh_CN/mobs.txt
4. 地图与地砖
https://florr.io/static/maps/{map}.tmj
https://florr.io/static/tiles/{tile}.svg
https://florr.io/static/tiles/tileset.tsj

五、实用调用示例（JavaScript）
// 获取花瓣图片
function getPetalUrl(id, rarity = 0) {
  if (rarity === 0) return `https://florr.io/petals/${id}.svg`;
  return `https://florr.io/petals/${id}_${rarity}.svg`;
}

// 获取怪物图片
function getMobUrl(id) {
  return `https://florr.io/mobs/${id}.svg`;
}

// 示例
console.log(getPetalUrl(5, 7)); // Rose Super
console.log(getMobUrl(4));      // Bee
六、注意事项
	1	CORS：直接在浏览器跨域加载官方 SVG 通常没问题（官方允许）。如果遇到限制，可像 maps.ashish.top 一样用代理。
	2	稀有度不存在：某些花瓣没有对应稀有度的 SVG，会 404。
	3	更新：游戏更新后 ID 可能新增，但旧 ID 一般不会变。
	4	完整数据源：推荐直接解析官方 petals.txt / mobs.txt，或参考 official-florrio.fandom.com。
