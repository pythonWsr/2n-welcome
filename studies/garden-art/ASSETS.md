# Garden art-direction study assets

Local copies of the 1K glTF/JPEG variants of Poly Haven's CC0 assets:

- Rock Face 01, Dario Barresi — https://polyhaven.com/a/rock_face_01
- Rock Moss Set 01, Kless Gyzen — https://polyhaven.com/a/rock_moss_set_01
- Fern 02, Rob Tuytel — https://polyhaven.com/a/fern_02
- Forest Ground 01, Rob Tuytel — https://polyhaven.com/a/forrest_ground_01

License: https://polyhaven.com/license (CC0). Download metadata and MD5 checks
come from https://api.polyhaven.com/files/{asset_id}. Reproduce locally with
`node scripts/fetch-garden-study-assets.mjs`. The API is not called at runtime.

Only a single Garden study camera shot is in scope. No Desert assets are used.
