# Model Study 02 — direction selection

Select C (Architectural) for continued blockout work, not production integration.

- A: strongest mass and low-angle weight; still reads too much as one thick angular glyph. The plinth makes the base heavy.
- B: cleanest planar face and changing depth; the diagonal is too slender for monumentality. Close views risk looking like folded signage.
- C: a recessed diagonal web relates a deep footing to a separate upper volume. The side view carries structural information rather than just extrusion depth. Current weakness: top-heavy proportions and a generic portal n.

Evidence: four views per candidate generated from the actual triangle geometry using the checked-in CPU renderer. These are neutral diffuse geometry checks, not GPU screenshots or metal renders. A/B/C remain available for comparison.

Next refinement: strengthen the C web and its seating, remove the incidental projecting bearing tab, vary n pier depth and make its lintel a designed spatial member.
